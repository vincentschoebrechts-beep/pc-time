How to update

  1. In PC Time, click “Quit”.
  2. Extract the zip and put the new PCTime.exe in the same folder as the old one (replace it).
  3. Start PCTime.exe: your history is kept.

First install

  1. Extract PCTime.zip (right-click > Extract All).
  2. Put the PCTime folder somewhere it will stay (e.g. Documents).
  3. Double-click PCTime.exe.

Windows may show “Windows protected your PC” because the app is not signed: click “More info”, then “Run anyway”.
